# Lab 04: In-Process Tool Execution & ACI Design

**Track:** Track B: Tool Engineering

## Systems Context
This laboratory investigates In-Process Tool Execution & ACI Design from first principles, emphasizing systems trade-offs, boundary invariants, and deterministic failure recovery.

## Objectives
1. Implement the core architectural pattern.
2. Execute the A/B control experiment.
3. Inject chaos and diagnose failures using `/drill`.
4. Defend the design decisions via `/defend`.
