# Lab 09: Transactional Workspaces & Shadow-Git Checkpoints

**Track:** Track C: Harness Engineering

## Systems Context
This laboratory investigates Transactional Workspaces & Shadow-Git Checkpoints from first principles, emphasizing systems trade-offs, boundary invariants, and deterministic failure recovery.

## Objectives
1. Implement the core architectural pattern.
2. Execute the A/B control experiment.
3. Inject chaos and diagnose failures using `/drill`.
4. Defend the design decisions via `/defend`.
