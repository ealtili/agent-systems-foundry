# Lab 05: Deadlines, Cancellation & Defensive Dispatch

**Track:** Track B: Tool Engineering

## Systems Context
This laboratory investigates Deadlines, Cancellation & Defensive Dispatch from first principles, emphasizing systems trade-offs, boundary invariants, and deterministic failure recovery.

## Objectives
1. Implement the core architectural pattern.
2. Execute the A/B control experiment.
3. Inject chaos and diagnose failures using `/drill`.
4. Defend the design decisions via `/defend`.
