# Lab 07: Capability-Based Security & Untrusted Ingestion

**Track:** Track F: Zero-Trust Security

## Systems Context
This laboratory investigates Capability-Based Security & Untrusted Ingestion from first principles, emphasizing systems trade-offs, boundary invariants, and deterministic failure recovery.

## Objectives
1. Implement the core architectural pattern.
2. Execute the A/B control experiment.
3. Inject chaos and diagnose failures using `/drill`.
4. Defend the design decisions via `/defend`.
