# Lab 02 Experimental Design

## Control Experiment
- System A (Control): Raw completion with hidden unvalidated thinking blocks.
- System B (Experiment): Structured output with explicit reasoning artifacts (plan, evidence, confidence) separated into schema fields.

## Hypothesis & Metrics
- **Independent Variable:** Architectural mechanism under test.
- **Hypothesis:** Isolating reasoning artifacts into typed fields increases model confidence accuracy and reduces post-generation extraction latency by >40%.
- **Dependent Metrics:**
  - Task completion rate (%)
  - Round-trip latency (ms)
  - Token overhead delta (%)
  - Failure recovery rate (%)
