# Lab 17: Scoped Rules, Slash Commands & Multi-File Refactoring

**Track:** Track G: Claude Code Platform

## Systems Context
This laboratory investigates Scoped Rules, Slash Commands & Multi-File Refactoring from first principles, emphasizing systems trade-offs, boundary invariants, and deterministic failure recovery.

## Objectives
1. Implement the core architectural pattern.
2. Execute the A/B control experiment.
