# claude-agent-foundry
Production-grade workbench and interactive curriculum for mastering Claude 5.5+, Claude Code orchestration, MCP servers, and zero-trust agentic architectures.
## Claude Agent Foundry
Claude Agent Foundry is an interactive, test-driven engineering lab designed to master the Anthropic stack—from low-level API mechanics to multi-agent orchestration inside Claude Code. Rather than passive tutorials, this repository operates as a live harness where Claude Code acts as your Staff Systems Architect, adversarial code reviewer, and drill instructor.

Core Pillars:
- Model Mechanics (Claude Sonnet/Opus 5.5 & Fable 5.1): Adaptive thinking, effort routing, prompt caching, and strict schema enforcement.
- Claude Code Mastery: Scoped rules (.claude/rules/), custom slash commands (.claude/commands/), automated pre-tool/post-tool hooks, and isolated subagent delegation.   
- Model Context Protocol (MCP): Designing, securing, and testing custom MCP servers (resources, tools, prompts) with strict input sanitization and least-privilege boundaries.
- Resilient Agent Loops: State machines, deterministic error recovery, human-in-the-loop (HITL) approval gates, and automated trajectory evaluations.
