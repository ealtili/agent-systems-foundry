### Mastery Dimensions Legend
- **E (Explain):** Articulate the underlying mechanism, failure modes, token cost, and architectural trade-offs.

- **V (Evaluate):** Empirically prove behavior using A/B control experiments, token counters, and latency metrics.
- **C (Choose):** Defend when NOT to use this architecture and select superior alternatives.
